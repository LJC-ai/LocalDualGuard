# DualGuard-Student（DualGuard 学生版）

> 面向 K12 / 高校编程学习与图形化编程（积木编程）课堂的**本地端学习诚信护栏**：在学生终端对"抄作业 / 照搬完整积木方案 / 篡改程序"等行为计数、警告、72 小时冻结，引导独立思考而非替代学习。

DualGuard-Student 与 DualGuard-Sec 共用同一套 `common/` 公共工具库（路径管理、AES+HMAC 加密存储、哈希校验、风控引擎），仅在 `main` 入口注入学生版业务规则与文案。两套版本数据目录相互隔离（`student` / `sec`），互不污染计数。

---

## 一、项目定位

DualGuard-Student 是一套**运行在学生本机 / 教室平板**的轻量学习诚信监护程序，配合教师端审核策略使用：

- **不是**作业批改系统、自动判题（OJ）或反作弊查重引擎本身。
- **不是**远程监控 / 屏幕录制 / 后门，不回传任何数据到外部服务器，所有记录仅以 AES-256 加密形式落盘在本机。
- **是**一个"学习诚信提醒员"：根据教师下发的 `audit_policy.json` 策略，对"直接抄作业、照搬图形化编程完整积木方案、篡改监护程序"等行为做计数 → 弹窗引导 → 累计达阈值后冻结相关功能 72 小时，并对策略文件做 SHA256 校验，被篡改时自动恢复。

核心理念：**引导学习思路，而非惩罚学习**。弹窗文案以"提示独立思考"为主，而非"作弊指控"。

## 二、使用场景

| 场景 | 说明 |
|------|------|
| 图形化编程课堂（Scratch / 积木编程） | 提醒学生不要直接照搬他人完整积木方案，鼓励先理解再拼搭 |
| K12 编程作业本机环境 | 在学生本机对"粘贴完整作业答案"等行为做计数与温和提示 |
| 高校编程实验机房 | 实验课对学员本机操作做合规留痕，事后可导出加密记录复盘 |
| 编程竞赛 / 课堂小测 | 防止学生篡改监护程序、防系统时间回拨绕过计时 |
| 编程学习社团 / 兴趣班 | 在社团设备上做学习诚信引导，培养独立完成习惯 |

## 三、核心能力（基于 `common/` 公共库）

- **违规计数 + 72 小时冻结**：单调计数器（`monotonic.state`）防系统时间回拨绕过。
- **AES-256 + HMAC 加密存储**：违规记录（`violations.enc`）防篡改、防读取，保护学生隐私。
- **审核策略哈希校验 + 自动恢复**：`audit_policy.json` 的预期 SHA256 存于 `audit_policy.sha256`，被篡改时从 `backup/` 自动还原并弹篡改警告。
- **可插拔前置审核 AI**：`pre_audit` 接口允许教师 / 教研注入自定义"学习诚信"判定规则。
- **温和文案**：弹窗以"学习引导"语气为主，避免对学生造成"作弊者"的负面标签。
- **跨平台**：Windows（学生平板/笔记本）+ Linux（机房服务器/学生机）。

数据目录约定（见 `common/paths.py`）：

```
Windows: %PROGRAMDATA%\DualGuard\student\
Linux  : /var/lib/dualguard/student/
```

4. **告知义务**：在学生设备上部署前，校方 / 教师有义务提前书面告知学生及监护人"本机存在学习诚信监护程序及留痕行为"，并符合当地教育法规要求。

> ⚠️ **DualGuard-Student 是学习引导员，不是作弊指控器。**

- 🚫 **禁止**将本程序计数结果直接作为"认定学生抄袭 / 作弊"的唯一依据对外公布或处罚。

- 🚫 **禁止**抄作业、粘贴他人完整答案冒充独立完成；本程序旨在引导你先理解思路再动手。

## 六、快速开始

### 6.1 安装（终端用户）

- **Windows**：双击 `DualGuard-Student-Setup-x.y.z.exe` → 安装向导 → 完成。详见 [docs/packaging.md](docs/packaging.md#windows-exe-安装与卸载)。
- **Linux**：`sudo dpkg -i dualguard-student_x.y.z_amd64.deb` → 服务自启。详见 [docs/packaging.md](docs/packaging.md#linux-deb-安装与卸载)。

### 6.2 运行

安装后程序以后台服务 / 托盘程序形式常驻，读取 `config.yaml` 与审核策略 `audit_policy.json` 生效。配置说明见 [config.yaml](config.yaml)。

### 6.3 开发者：从源码运行

```bash
# 仓库根目录
python -m pip install -r requirements.txt
# 以 student 版本启动
python -m dualguard_student.main
```
